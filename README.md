# Little Neighborhood Study Club

A self-contained personal "study with me" website with an original illustrated tiger and neighborhood.

## Run
Open `index.html` in a modern browser. No server or backend is required.

## Included
- Original CSS/SVG-style illustrated world (no third-party character artwork)
- Animated tiger built from layered vector/CSS shapes
- Neighborhood map with 8 study locations
- 15/25/45/60 minute study timer
- Completion star system stored in localStorage
- Break scene with original neighborhood friends
- Automatic day/night mode based on the browser's current time
- Responsive mobile layout
- Optional tiny sound cue
- Reduced-motion support

## Notes
The artwork is intentionally original and avoids official characters, logos, screenshots, or copied assets. The fonts are loaded from Google Fonts when online; the site remains usable if the font request fails.
